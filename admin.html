连接 GitHub 仓库

后台通过 GitHub API 直接修改仓库里的 content/site.json 和图片文件。 保存后 Cloudflare Pages 会自动重新部署，通常 30 秒内生效。

  1. 打开 GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens
  2. Repository access 只勾选这个网站的仓库
  3. Permissions → Contents 设为 Read and write
  4. 生成后把 token 粘到下面（只显示一次，记得复制）

Token 只存在这台电脑的浏览器里，不会发给任何人。
