01这是个什么服务器

EarthMC 是一个以 Towny 插件为基础的地缘政治服务器（但是没有战争插件）， 加入城镇进行发展是服务器大多数玩家的选择。

我猜你可能想知道，为什么在加入我们之前，你已经收到了无数城镇的邀请—— 这是因为居民数量的增加可以提高一个城镇的面积上限， 很多城镇疯狂拉人就是为了增加这个上限。当然，这不是我们拉你进来的目的—— 我们希望，我们能够共同建设一个团结友好的游戏社区，留下美好的游戏回忆。

进入服务器

join.earthmc.net
  • Java 版 + 正版账号。服务器使用正版验证，离线账号无法进入。
  • 版本 1.21.11 以上。原版客户端即可加入，不需要安装任何模组。
  • 服务器架设在欧洲，国内延迟偏高属于正常现象。
注意
play.earthmc.net 是已停用的旧地址，唯一有效地址是 join.earthmc.net。服务器满人时会排队，输入 /queue 可以查看你排在第几位。

地图

输入 /map 可以打开服务器地图的网页链接（也可直接访问 map.earthmc.net）。地图比例为 1:500。

注意，玩家潜行时或头顶上有方块遮挡时，在地图上是不会显示位置的 （当然，这也可以用于躲避猎人的追杀）。

一个招募小技巧
每个玩家都有专属域名，格式为 你的ID.earthmc.net。 用这个域名进来的朋友会自动加入你的城镇，不用手动邀请。 拉朋友一起玩的时候，把你的专属域名发给他就行。

02聊天频道

服务器采用频道制：先加入频道，再正常打字。不是每次发言都要带前缀。

/g 可加入国际聊天频道，/chinese 可加入中文聊天频道， /local 可加入附近聊天频道，/nc 可加入国家聊天频道， /tc 可加入城镇聊天频道。 如果你不想看到某个频道的信息，可以输入 /ch leave 频道名。

频道描述
/global全球频道，仅限英语
/local本地频道，仅距你较近的玩家可见
/tradechat买卖等交易频道
/ch join premium会员玩家频道
/nc 或 /nationchat国家频道
/tc 或 /townchat城镇频道
/[语言]一系列的语言频道，如 /chinese 为加入中文频道

聊天指令

/ch leave [频道]离开频道
/msg [玩家] [信息]向玩家发送信息

03传送

你可以传送至自己的城镇、你所在国家的城镇、盟国的首都及你的床边。 EarthMC 不支持玩家之间的传送，没有 /tpa 这类指令。

指令描述

/t spawn [城镇]传送至指定城镇
/t warp [传送点]传送至城镇传送点
/t warp [城镇] [传送点]传送至指定城镇的指定传送点
/n spawn传送至自己国家的首都
/n spawn [国家]传送至指定国家
/res spawn 或 /home回到你的床边
/warp查看可用传送点

仅限新玩家（入服时间 < 24 小时）

指令描述
/rtp传送至地图上的随机位置
/rtp region [地区]传送至所选区域内的随机地点，例如非洲（Africa）
城镇传送点（warp）
城镇达到 128 区块后才解锁传送点，且每天要交维护费：第一个 4 金， 之后每个约为前一个的 1.5 倍（4 → 6 → 9 → 14）。 佛山的对外传送点（Outsider Spawn）目前未开放，所以非明国玩家无法直接传送到佛山。

04金锭与商店

服务器的货币是金锭（简称 g），一般可以通过挖矿或"签到"获得。

怎么获得金锭

所谓签到，就是输入 /vote 在两个网址中给服务器投票。 投票后可以获得一个 gold crate，右键打开 gold crate 后可以获得随机数量的金锭。 每 24 小时最多 4 个金箱。

每当服务器积累 5000 个投票后，就会触发一次 voteparty 事件， 每个在线玩家可获得一个 giant gold crate（奖励金锭的数额很多）。 你可以通过 /vp 指令查看服务器触发 voteparty 事件还差多少个投票。

金锭可以用于在商店中购买物品、建立城镇/国家、扩大城镇区块等等， 请一定要保管好你的金锭。最安全的地方是末影箱——死亡不会掉落，别人也打不开。

服务器的大型商店

服务器有几个大型商店，如 /n spawn ob、/n spawn mali、 /n spawn brazil 等。/n spawn western_china 是国营商店。

银行

指令描述
/t deposit [数量]向城镇银行捐钱（要在 home 区块或 bank 区块操作）
/t withdraw [数量]从城镇银行取钱，只有市长或议员（Councillor）有此权限
/n deposit [数量]保存黄金至国家银行
/n withdraw [数量]从国家银行中取出黄金

开商店（QuickShop）

商店必须建在 shop 类型的区块上。放置箱子后，手持商品左键点击箱子， 按提示输入价格即可。最低是 1 金换 64 件物品。

指令描述
/qs buy切换商店至购买模式
/qs sell切换商店至收购模式
/qs price [价格]更改商店价格
/qs size更改商店销售数量
/qs staff add [玩家]为您的商店增加管理人员
/qs staff remove [玩家]从您的商店移除管理人员
/qs staff clear清除所有工作人员
防骗提醒
/t forsale 或 /t fs 是出售整个城镇的指令。 部分玩家有可能诱使你输入这一指令以骗取你的城镇。任何让你敲这条指令的人，都值得怀疑。

05城镇

城镇是 EarthMC 的基本单位。加入城镇进行发展，是服务器大多数玩家的选择。

加入与创建

收到邀请后输入 /accept 即可加入；开放加入的城镇可以直接申请：

/t join <城镇名>

自己建城需要 64 金锭，且要站在未被认领的土地上：

/t new <城镇名>

建成后占地 1 区块，区块上限为 12。之后每增加 1 位居民，上限增加 12； 加入国家后还会获得基于国家人口的国家加成。

为城镇圈地每块 16 金锭，费用从城镇银行扣除：

/t claim

42 天规则

注意：玩家若 42 天不上线，其在服务器的 Towny 信息会被删除。 若该玩家是一个城市的唯一成员，这个城镇也会随着玩家信息的删除而被删除—— 有些人会专门寻找这样的城市，当市长快删号时加入城镇以夺取该城市。

市长 42 天不活跃时，会按顺序由任职最久的议员继任；没有议员则由最活跃的居民接任。 所以长期不上线，一定要提前打招呼。

过度索取（OC）

如果一个城镇占领的区块数超过它的上限（通常因为居民流失）， 其他城镇可以用 /t takeoverclaim 夺取这些超额区块。限制条件：

  • 只有面积大于 12 区块的城镇才能被夺取。
  • 城镇的 home 区块受保护，永远不能被夺。
  • 城镇必须建立超过 30 天，才有资格夺取别人。
  • 每天最多使用 24 次。
  • 被夺取的一方可以花钱买区块护盾：超限部分每 4 块、每 24 小时 1 金。

06国家

国家由城镇组成。首都由一个国家内的城镇担任，国家频道、传送与外交都围绕它展开。

创建国家需要 2048 金锭，且只有市长才能创建，所在城镇自动成为首都。 城镇加入国家需要满足距离要求：首都 3500 格范围内的城镇可以受邀加入， 每有一个城镇加入，范围向外扩展 1000 格。

07自定义空间

Quarter 在官方中文文档中被称为"自定义空间"。 标准区块只能管一个 16×16×全高的柱子，而 Quarter 是可以自定义大小的长方体。

类型

Quarter 类型在默认的城镇、区块类型的基础上进行扩展。市长和议员可以更改 Quarter 类型：

/q type [类型]
Quarter 类型描述
公寓（Apartment）默认的 Quarter 类型
客栈（Inn）允许使用 Quarter 内的床铺
车站（Station）允许使用船只和矿车等载具
注意
您必须将 Quarter 设置为大使馆（Embassy），才能让外来者也享有车站（Station）等权限。 例如，当您希望城镇外的人也可以使用车站中的船只和矿车， 您必须将 Quarter 设置为大使馆方能使其对外来者（Outsider）生效。

创建

手持燧石（没有就 /q wand 免费领一个），左键点第一个角、右键点对角， 形成一个长方体轮廓，然后 /q create。 长方体必须完全位于同一个城镇内，不能包含未认领的荒野，不能与已有 Quarter 重叠， 也不能超出世界高度上下限。

08区块与头衔

区块是城镇内部的地皮单位。市长可以给居民授予头衔，不同头衔对应不同权限。

区块类型

区块类型描述
默认（default）默认区块类型，适用于个人建筑、住宅等
店铺（shop）允许创建店铺
竞技场（arena）允许玩家对战（PvP），死亡不掉落物品和经验
保险库（Vault）禁止所有受信任玩家和议员进入该地块。只有镇长和被明确信任的玩家 / plot trust add 才能使用该地块
农场（Farm）允许收割作物，但不能破坏其他类型的方块；允许对生物造成伤害
大使馆（Embassy）允许来自其他城镇的居民购买区块。被购买后，区块所有者仍享有主权。这多用于在不同城镇开设商店、拓展海外市场
客栈（Inn）允许任何人使用区块内的床
荒野（wild）仅允许开采石头（安山岩、花岗岩、闪长岩）、矿物、矿石和深板岩。这一权限支持在设立公共矿场的同时保护建筑物

区块指令

指令描述
/plot fs [价格]设置区块领取价格
/plot claim购买区块
/plot unclaim放弃区块
/plot set [区块类型]设置区块类型
/plot set [最小加入天数/最大加入天数/clear]根据玩家加入城镇的日期，限制他们是否可认领区块，允许市长为新玩家或老玩家预留土地。此设置不影响大使馆地块
/plot set perm [build/destroy/switch/itemuse] [resident/ally/nation/outsider]设置区块权限，及对应的身份组（镇民/盟友/国家/外来者）权限
/plot toggle [explosion/fire/mobs/pvp]设置区块（爆炸/火焰蔓延/生物生成/允许 pvp）权限

城镇头衔

市长可以给居民授予头衔：

/t rank add [玩家] [头衔]
头衔权限
议员（Councillor）对所有城镇地块的完全访问权限，并可使用除 /t unclaim、/t set mayor、/t delete 等之外的大部分城镇指令。议员可以踢出除市长和其他议员之外的所有人，从城镇银行提取金币，编辑城镇/区块的权限。由于议员可能对城镇造成不利影响，此身份应仅授予最被信赖的市民
受信任者（Trusted）与议员级别类似，可以无视区块所有权访问所有区块，但不能像议员那样使用城镇指令
建造者（Builder）可以编辑非个人所有区块。只要地块不属于某个玩家，他们就可以在城镇的任何地方建造、打开箱子、使用物品和破坏方块
房地产经纪人（Realtor）可以将城镇中目前无人拥有的地块挂牌出售，也可以将其下架并设置为大使馆。拥有城镇内所有无人拥有区块的 /plot 有关权限。此外还拥有在自定义空间（Quarter）内驱逐、出售、改变颜色、更改类型及切换大使馆功能的权限
定居者（Settler）可以为城镇认领新区块 /t claim
招募者（Recruiter）可以邀请其他玩家入城 /t add [玩家]
警察（Police）可以放逐玩家 /t outlaw add [玩家]
财务主管（Treasurer）可以从城镇银行提取黄金 /t withdraw [数量]

11加入佛山

我们所在的城市是佛山市（Foshan），位于大明共和国广东省。 佛山的城镇公告栏写着："一座美丽而现代的城市，欢迎你的加入。"

我们是服务器中明国（Ming）的成员。明国是 EarthMC 中华地区规模最大的华人国家， 2026 年 4 月 23 日建国于南京，现任皇帝为 Judgemen_t，首相为 PreviousYun， 首都为南京，欢迎输入 /n spawn 参观。

怎么来

  • 大明国民可以直接 /t spawn Foshan。
  • 非明国玩家目前无法直接传送——佛山的对外传送点未开放，需要先加入明国，或联系市长安排接应。
  • 佛山不开放自由加入，需要市长或议员邀请。

来了之后

  • 城市公寓 Upbeat Dwelling 是 Quarter 类型空间，可以领一间临时房间放东西、过夜。
  • 城内有公共商店与门禁，需要什么可以直接问市长。
  • 攒够 16 金后可以申请地块，用 /plot claim 买下，然后开始建造。
  • 建造前先看城市的风貌要求，别盖一栋和周围完全不搭的房子。
联系谁
游戏内私聊市长 bbdqz，或加入中文频道 /chinese 找人。 说明你的游戏 ID、大致在线时间、想做的事（建筑 / 挖矿 / 种田 / 经商）。
别当"42 天失踪人口"
连续 42 天不上线，你的 Towny 信息会被删除，地块也会回收。 要离开一段时间的话，提前在群里说一声。

12常见问题

一定要买正版吗？
是的。服务器开启正版验证，必须使用从 minecraft.net 购买的 Java 版账号。 离线账号、破解客户端无法进入，基岩版（手机、主机）也不能直连。
手机能玩吗？
EarthMC 只支持 Java 版，手机上的基岩版无法连接。 虽然存在第三方启动器可以在手机上跑 Java 版，但体验很差，也不在官方支持范围内。
建一座城要多少钱？
建城固定 64 金锭，之后每圈一块地 16 金，费用从城镇银行扣除。 新建国家需要 2048 金，且只有市长才能创建。
能传送到朋友身边吗？
不能。EarthMC 不支持玩家之间的传送，没有 /tpa 这类指令。 你只能传送到城镇出生点、国家首都、城镇传送点，或者自己的床。 这套设计是为了让地理位置真正有意义。
我的建筑会被拆吗？
在城镇领地内，非居民默认无法建造、破坏、开箱，是安全的。 但在荒野（未认领区块）没有任何保护，任何人都可以拆。 服务器规则明确允许掠夺和偷窃，保护财产是玩家自己的责任。
多久不上线会被删数据？
连续 42 天未登录，你的 Towny 信息会被删除。 如果你是城镇唯一成员，城镇也会消失。市长 42 天不活跃会由议员或最活跃居民继任。
为什么全球频道不能打中文？
这是服务器规则：/global 仅限英语，方便各国玩家交流。 中文玩家集中在 /chinese 频道，进去正常打字就行。
别人能抢我的地吗？
正常情况下不能。只有一种情况：你的城镇占领区块数超过上限（通常因为居民流失）， 其他建立超过 30 天的城镇可以用 /t takeoverclaim 夺取超额部分。 城镇的 home 区块永远受保护。
怎么赚钱最快？
前期靠 /vote 投票（每天最多 4 个金箱）和挖矿。 中期靠开店——但店要开在人流大的地方，首都的商业区通常最赚。
迷路了怎么办？
/t spawn 回自己城镇，/n spawn 回国家首都， /home 回床边。如果还没加入城镇，用 /map 对照坐标走回来， 或者入服未满 24 小时的话直接用 /rtp 重新开始。
