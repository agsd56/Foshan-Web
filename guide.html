新手指南 · Getting Started

从零开始BEGINNER'S GUIDE TO EARTHMC

这份指南写给第一次进入 EarthMC 的人。不需要任何经验， 按顺序做完这十一步，你就会有一座城、一块地，和一群邻居。

STEP 01开始之前

EarthMC 是一个以真实地球为地图的 Minecraft 服务器。玩家在 1:2000 缩放的地球上建城、立国、结盟、开战。 在动手之前，先确认三件事。

你需要一份 Java 版 Minecraft

服务器仅支持 Java 版，且使用正版验证——离线账号、破解客户端无法进入。 基岩版（手机 / 主机 / Win10 版）不能直连。

版本要对

服务器跟随最新正式版更新，进入前请把客户端升级到 最新正式版。 如果你用的是启动器的旧版本存档，建议新建一个独立的游戏配置。

不需要任何模组

原版即可进入。小地图、光影等客户端模组属于个人选择， 但任何影响公平性的作弊模组都会被封禁。

心态准备
EarthMC 是长期服务器，一座城往往要建几个月。不要急着一天造完， 也别因为第一天只有木头房子就放弃——现在地图上那些大城，起点都是几间木屋。

STEP 02进入服务器

服务器地址只有一个，记不住也没关系，本页可以直接复制。

join.earthmc.net

打开多人游戏

启动游戏 → 主菜单 → 多人游戏 → 添加服务器。

填写地址

服务器名称随意填（例如「EarthMC」），地址填 join.earthmc.net，点击完成。

等待资源包

首次进入会提示下载服务器资源包，选择接受。文件较大，慢的话耐心等一会儿。

出生点

你会出生在地图上的公共出生点。这里人很多、也很拥挤， 不要在这里建东西——先离开，再找地方落脚。

小提示
进服后按 T 打开聊天框，输入 /help 可以看到服务器支持的全部指令。 本文列出的命令以常用版本为准，若与游戏内不一致，请以 /help 为准。

STEP 03注册与登录

EarthMC 用密码保护账号，第一次进入必须注册，之后每次进入都要登录。

首次注册

在聊天框输入下面这条命令，两个密码要一致：

/register <密码> <密码>

例如：/register mypass123 mypass123

以后每次登录

/login <密码>
请务必注意
这个密码只用于服务器，不要和你的邮箱、微信或其他账号使用同一个密码。 忘记密码需要联系管理员处理，比较麻烦。

登录成功后，你的位置会被记住。下次进入服务器时，如果提示需要登录， 在聊天框输入 /login 加密码即可。

STEP 04第一小时做什么

第一小时的目标只有两个：活下来，以及找到一个愿意收留你的城镇。 不要急着建城。

先离开出生点

朝任意方向走 500 到 1000 格。出生点周边通常已经被认领或规划， 在那里建的东西会被清理。

收集基础物资

砍树拿木头做工具，找石头做镐，打点动物解决食物。 有床就睡一觉，把重生点设在你落脚的地方。

不要主动攻击别人

服务器有 PvP 规则，但在野外主动挑事很容易结仇。 前期你打不过任何人，绕开就好。

找一座城镇

加入现成的城镇，比从零建城划算得多：有保护、有传送点、有商店、有人教。 具体见下一步。

STEP 05加入城镇

城镇是 EarthMC 的基本单位。它决定了你的领地是否受保护、能不能使用传送点、 以及你属于哪个国家。

方式一：加入别人的城镇（推荐）

最省事的路。找到愿意收人的城镇，由市长或议员把你加进去，或者你主动申请：

/t join <城镇名>

加入后，你自动成为该城镇所属国家的居民：

/n join <国家名>

方式二：自己建城

如果你想从零开始，需要满足两个条件：足够的金币，以及一块没被占的地。

/t new <城镇名>
建城要多少钱？
建城需要支付金币，费用随距离变化——离出生点越远，价格越高。 最便宜的地段通常也要几十金起步。所以新人一般先加入城镇攒钱，再考虑自立。

加入城镇之后

  • 你可以在城内认领自己的地块（见第 07 节）。
  • 城镇通常有公共仓库、农田与工具，可以免费使用。
  • 城镇领地内，其他玩家无法破坏方块或打开你的箱子。
  • 你可能需要缴税，具体金额由市长设定。

离开城镇

/t leave

离开后你会失去该城镇的领地保护，城内的个人地块也会被回收。想清楚再走。

STEP 06金币与谋生

EarthMC 的经济以金锭为硬通货。建城、认领区块、缴税、买卖，全靠它。

怎么赚钱

卖原材料给商店

最稳的起步方式。原木、石头、铁矿、煤炭、农作物，都是商店常年收购的货。 城内商店通常有收购箱，把东西放进去就能拿到钱。

挖矿

金矿、铁矿、钻石在地下都有价值。注意不要在别人的领地下面挖。

种田与养殖

自动化农场是长期收入来源。小麦、胡萝卜、甘蔗、南瓜都有人收。

接建筑委托

会造房子的人在服务器里很吃香。帮别人建一栋楼，报酬往往比挖矿高得多。

常用财务命令

命令作用
/money查看自己的金币余额
/pay <玩家> <金额>转账给其他玩家
/baltop查看服务器财富排行榜
/t deposit <金额>向城镇金库存款
/t withdraw <金额>从城镇金库取款（需权限）
防骗提醒
不要相信"先给我钱，我帮你建城"之类的承诺。所有交易尽量当面完成， 或者通过商店箱子进行。被骗的钱基本追不回来。

STEP 07领地与保护

EarthMC 的地图按区块划分，每个区块 16 × 16 格。 城镇通过认领区块来扩张领土，被认领的区块受规则保护。

认领与放弃

命令作用
/t claim认领脚下所在的区块（消耗金币）
/t unclaim放弃脚下所在的区块
/t claim outpost在远处建立飞地据点

地块：城里的"房产证"

城镇内部的区块可以切分成地块，由居民认领或买卖：

命令作用
/plot fs <价格>把自己的地块挂牌出售
/plot claim购买脚下挂牌的地块
/plot clear清空地块上的方块（谨慎使用）

保护范围

  • 城镇领地内：非居民默认无法建造、破坏、开门、使用容器。
  • 野外：没有保护。任何人放的火、炸的 TNT、拆的方块都不会被阻止。
  • 战争期间：敌对国可以攻击并占领你的城镇区块，这叫 OC（Overclaim）。
为什么要把家建在城里？
因为野外的箱子随时可能被翻，建筑随时可能被拆。 城镇领地是唯一能让你安心下线的地方。

STEP 08命令速查

把这一页存进书签。下面是最常用的命令，够你玩上一个月。

传送与移动

命令作用
/spawn回到服务器公共出生点
/t spawn <城镇>传送到指定城镇（如 /t spawn Foshan）
/n spawn <国家>传送到指定国家的首都
/tpa <玩家>请求传送到某位玩家身边
/tpaccept接受别人的传送请求
/tpdeny拒绝传送请求

聊天频道

命令作用
/g <内容>全球频道，全服可见
/lc <内容>本地频道，附近玩家可见
/tc <内容>城镇频道，同城可见
/nc <内容>国家频道，同国可见
/msg <玩家> <内容>私聊
/r <内容>回复最近一条私聊

信息查询

命令作用
/t <城镇>查看城镇信息
/n <国家>查看国家信息
/resident <玩家>查看某位玩家的资料
/t list列出服务器所有城镇
/n list列出服务器所有国家
/t top城镇排行榜

城镇管理（市长 / 议员）

命令作用
/t add <玩家>邀请玩家加入城镇
/t kick <玩家>移出居民
/t set board <文字>设置城镇公告栏
/t set mayor <玩家>转让市长职位
/t set taxes <金额>设置居民税率
/t set pvp on|off开关城内 PvP
/t set spawn把当前位置设为城镇传送点
/t rank add <玩家> <职位>授予职位（议员、建筑师等）
记不住怎么办？
在游戏里输入 /t 或 /n 不带参数，会列出所有子命令和说明。 /help 则是总目录。

STEP 09加入佛山

如果你看到这里，说明你大概已经决定要玩下去了。欢迎考虑佛山。

先进来看一眼

在游戏内输入 /t spawn Foshan，你会出现在城市出生点。 先逛逛，看看这里是不是你想住的地方。

找到市政厅

城内设有公告栏与门禁登记点。也可以直接在世界频道或私聊联系市长 bbdqz，说明来意。

说明你的情况

告诉对方：游戏 ID、大致在线时间、想做的事（建筑 / 挖矿 / 种田 / 经商）。 不需要写得很正式，一句话就够。

拿到临时住所

通过审核后，你会被加入城镇，并可以在城市公寓 Upbeat Dwelling 领到一间临时房间，存放物品、过夜。

申请一块地

攒够金币后，向东平河沿岸的住宅区申请地块。 建造前请先看城市的风貌指引，避免风格冲突。

成为大明国民

加入佛山即自动成为大明共和国居民。 你可以在国家频道 /nc 里认识其他城市的玩家。

佛山目前不开放自由加入
需要市长或议员邀请。如果你暂时联系不上人，可以先加入大明的其他城镇， 等有空位再转过来。转城不会丢失你的物品。

STEP 10礼仪与禁忌

EarthMC 的规则不多，但踩线的代价很直接：轻则被踢出城镇，重则被全服通缉。

绝对不要做的事

  • 偷窃——翻别人的箱子、拿走展示框里的物品，都算偷。
  • 破坏——拆别人的建筑、放火、倒岩浆、埋 TNT。
  • 诈骗——收了钱不办事，或者用假交易骗人。
  • 使用作弊客户端——飞行、透视、自动战斗，一律封禁。
  • 开小号规避惩罚——这是最严重的违规之一，会牵连整个城镇。

应该做的事

  • 进入别人的城镇前先打招呼，不要擅自闯入私人住宅。
  • 公共建筑不要随意改建，有想法先提出来。
  • 用完公共设施（熔炉、工作台、农田）记得恢复原样。
  • 看到新人遇到困难，帮一把——这个服务器靠这个运转。
  • 国家之间的战争是游戏的一部分，但不要上升到人身攻击。
关于"战时行为"
战争状态下，攻击敌对国城镇是允许的玩法。但针对平民的恶意破坏、 利用漏洞刷物品，仍然会被管理员处理。打仗也要讲规矩。

STEP 11常见问题

一定要买正版吗？
是的。服务器开启了正版验证，离线账号无法进入。Minecraft Java 版需要单独购买， 与基岩版不通用（部分版本会赠送，以官方说明为准）。
手机能玩吗？
EarthMC 是 Java 版服务器，手机上的基岩版无法直连。虽然存在第三方启动器可以在手机上运行 Java 版，但操作体验很差，也不在官方支持范围内，不建议以此作为主要方式。
玩这个要花钱吗？
服务器本身免费。你只需要一份正版 Minecraft。服务器内的一切交易都用游戏内的金币， 不涉及真实货币。
建一座城要多少钱？
建城需要支付金币，费用与距离有关，离出生点越远越贵，最低通常也要几十金。 除此之外，每认领一个区块都要额外花费。所以新人一般先在别人的城里攒钱。
我的建筑会被拆吗？
在城镇领地内，非居民无法破坏你的建筑，是安全的。 但在野外（未被认领的区块），任何人都可以拆、可以烧，没有任何保护。 这就是为什么要把家安在城里。
多久不上线会被踢出城镇？
服务器没有统一的自动清理规则，由各城镇自行决定。 佛山目前没有强制的离线期限，但如果长期不登录且没有提前说明， 地块可能会被回收再分配。离开前打个招呼就好。
可以用中文交流吗？
可以。大明共和国是中文国家，国家频道、城镇频道里基本都是中文。 全球频道 /g 以英文为主，但中文玩家很多。
迷路了怎么办？
输入 /t spawn <你的城镇> 回城，或者 /spawn 回公共出生点。 建议一开始就把城镇设为常用传送点，别在野外乱走太远。
可以和朋友一起建城吗？
可以。一人建城，其他人加入，共同认领区块、共同出资。 记得提前商量好市长人选和地块分配，很多城邦都是因为这件事散伙的。
服务器会重置地图吗？
EarthMC 采用"周目"制，每隔数年会在新地图上开启新一轮。 当前周目始于 2026 年 5 月，短期内不会重置。你的建筑可以长期保留。
